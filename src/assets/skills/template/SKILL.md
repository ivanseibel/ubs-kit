# UBS Template

## When to use this skill

Use this skill when you need to start a new UBS file and want the canonical
section structure.

## Steps

1. Copy the template from `ubs-template.md`.
2. Fill in each section in order.
3. Ensure the UBS ID and Primary Behavior are set.
